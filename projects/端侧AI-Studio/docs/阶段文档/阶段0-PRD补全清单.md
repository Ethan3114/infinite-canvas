## 已定（不再重复问）

- 只在你自己的电脑上跑，不部署，不启用腾讯云套餐。
- 文本转写用 DeepSeek。这把钥匙上的模型能看图。用户写下要求后，由它看着商品图或角色参考图，收成一张生成卡。你确认这张卡之后才生成。
- 生图用商汤。3 把钥匙能生图。不设每月费用上限。同一时间只发出一个商汤请求，上一张完成或失败后才换下一把。
- 生视频只用蚂蚁数科大模型服务平台的视频模型，走你的免费档 Token Plan。不用蚂蚁的文本、生图或其他模型。文档入口：https://maas.antdigital.com/docs/intro
- 钥匙都不进仓库，也不贴到对话里。
- 样例图或你自己的图可以发给 DeepSeek、商汤、蚂蚁，不写进运行日志。
- 这次要做完的范围：电商素材工作流、批量短剧自动化工作流，并且要有画布。
- 动手前先查开源。查完的结论见下方「开源查过了」。只采用一个开源画布当底座，其余开源只借鉴做法，不把多个仓库叠成一个产品。
- 登录用邀请码。作品存在这台电脑上。图片 jpg、png、webp，单张不超过 10 MB。
- 什么叫生成得好，等第一次真出图时用 5 到 10 张打分。商品明显变样、主角换成另一个人，不能算过。
- 改尺寸用程序裁切或缩放。改风格、换 SKU、换镜头才重新生成。
- 批量出片是导出带镜头号的图片和视频片段，不在网页里做剪辑软件。
- 每一条任务确认一次生成卡，然后整批排队。不再把 6 张当成产品上限。

## 开源查过了（2026-11-04）

| 功能 | GitHub 上有什么 | 结论 |
| --- | --- | --- |
| 无限画布 | [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas)，MIT，约 9600 star，2026-10 仍在更新。能做画布、生图、参考图、视频、提示词和素材，接口按 OpenAI 兼容来接 | 采用这个当底座。DeepSeek 能按这类接口接。商汤生图和蚂蚁视频作为它上面的两种生成能力接进去 |
| 短剧分镜、角色、出片 | [HBAI-Ltd/Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app)，MIT，约 2 万 star，自带画布和短剧流程，但是桌面、手机、服务器一整套。[Forget-C/Jellyfish](https://github.com/Forget-C/Jellyfish)，Apache-2.0，剧本到分镜到一致性，没有把你的三家接口当作前提 | 只借鉴步骤：剧本、分镜、角色卡、确认、生成、导出。不把第二套软件跑起来 |
| 锁住同一个商品再换场景 | [clawnify/OpenStudio](https://github.com/clawnify/OpenStudio) 有 Subject lock，但绑的是另一家模型平台 | 只借鉴「锁住外观、只换场景」的做法 |
| 本机锁脸、锁风格 | PuLID、IP-Adapter、ComfyUI 都有 | 不采用。它们跑在本机模型上，接不上商汤和蚂蚁的云端接口 |
| 改尺寸 | 不需要一整套开源产品 | 用图片处理库裁切或缩放 |
| 人话收成生成卡 | 不需要再装一个开源产品 | 用 DeepSeek 的识图模型做 |

infinite-canvas 作者写了：项目还在开发，本地保存格式可能变；二次使用要保留原作者信息。按这个做。

## 已发现的矛盾（本轮裁决）

- 上一轮推荐「文本也用商汤，不接第二家」。你改成 DeepSeek，并说明模型能看图。裁决：转写用 DeepSeek 识图；生图仍用商汤。
- 上一轮把无限画布移出这次。你要求必须有画布，而且先查开源。裁决：画布在这次范围内，底座用 infinite-canvas。
- 上一轮推荐视频也用商汤。你改成蚂蚁免费档，且只用视频模型。裁决：视频只走蚂蚁视频模型，不用蚂蚁的其他模型。
- 开源里有整套短剧软件，也有本机锁脸仓库。裁决：不叠多套程序，也不把本机模型仓库接进云端接口。
