# 照着做清单：阶段 0 需求体检

这一阶段没有网页可点。你要核对的是：需求缺口是否都关掉了，而且还没有开始写代码。

1. 打开 `projects/端侧AI-Studio/docs/阶段文档/阶段0-PRD补全清单.md`。
2. 看到文首写着「清单状态：已关闭」。
3. 核对这 8 句是不是你要的：
   - 只在自己电脑上做，不上线。
   - 这次做完电商素材工作流和批量短剧工作流，并且用画布来做。
   - 转写用 DeepSeek，会看参考图，收成生成卡，你确认一次再生成。
   - 生图用商汤。3 把钥匙排队，不能同时用。
   - 视频只用蚂蚁免费档的视频模型。先出图，再做成短视频。额度不够可以加钱，但必须先报价，你同意才继续。
   - 画布用开源项目 infinite-canvas 当底座。别的开源只借鉴做法，不叠成好几套软件。
   - 样例图可以发给这三家，不写进日志。钥匙没有出现在对话和文件里。
4. 打开 `projects/端侧AI-Studio/docs/项目状态.md`，待确认问题一节应是「无」。
5. 确认产品文件夹里还没有 `backend/`、`frontend/`。有的话，说明提前做了下一段。

看到以上都对，在对话里回复「验收通过」。有哪句不对，直接说要改哪句。
