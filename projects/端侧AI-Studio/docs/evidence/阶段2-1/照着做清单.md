# 照着做清单：画布上的一条电商路径

页面已经在这台电脑上开着：http://127.0.0.1:8000

1. 打开上面的地址。邀请码填 `studio-demo`，点「进入画布」。
2. 整页就是画布。空白处可以拖动。商品、要求、生成卡都在画布上的节点里，不再有左侧表单。
3. 在「商品」节点里选「场景图」，点图片区域放上商品图，要求可以留着「放到木质桌面上，柔和日光」。
4. 点节点上的「写成生成卡」。生成卡会出现在右边的节点里。
5. 现在还没把钥匙放进 `backend/.env`，所以生成卡上应显示「还没有配置 DeepSeek 钥匙或识图模型名」。这不是一张假图。
6. 钥匙填好并重启后端之后，再点一次。你应先看到生成卡，点「确认出图」，再看到商汤出的图。刷新页面，图还在。

填钥匙时只改这一个文件：`projects/端侧AI-Studio/backend/.env`

- `DEEPSEEK_API_KEY` 填 DeepSeek 的钥匙
- `DEEPSEEK_MODEL` 填能看图的模型名
- `SENSETIME_API_KEYS` 填三把商汤钥匙，用英文逗号隔开

不要把钥匙贴回对话。改完后停掉原来的后端，重新运行 README 里的启动命令。
